# Example Notebook Files

This directory contains example notebook files in various formats, used for testing and development.

## Attribution

The example notebooks in this directory are from the [Jupytext demo](https://github.com/mwouts/jupytext/tree/main/demo) repository.

Jupytext is a tool for converting Jupyter notebooks to various text-based formats, created by Marc Wouts. These example files are used here for testing notebookx format parsing and conversion.

## Files

- `World population.ipynb` - Jupyter notebook format (JSON)
- `World population.pct.py` - Percent format
- `World population.lgt.py` - Light format
- `World population.spx.py` - Sphinx format
- `World population.md` - Markdown format
- `World population.myst.md` - MyST Markdown format
- `World population.pandoc.md` - Pandoc Markdown format
- `World population.Rmd` - R Markdown format
